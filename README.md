# Cebá - Mates artesanales

Este es mi proyecto de la Pre-Entrega de Talento Tech (Frontend JS).

Es una página web de una tienda de mates artesanales hechos a mano. La hice para practicar HTML y CSS.

## Qué tiene la página

- Inicio con una imagen y un botón
- Productos (mates en cards)
- Cómo curar un mate
- Reseñas de clientes
- Formulario de contacto

## Qué usé

- HTML
- CSS (Flexbox, Grid y media queries)
- Google Fonts
- Formspree para el formulario

## Cómo verla

Abrir el archivo `index.html` en el navegador.
